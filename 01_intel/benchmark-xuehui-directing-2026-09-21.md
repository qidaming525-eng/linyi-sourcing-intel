## 2. 他真正在讲什么 / What He Actually Teaches

### 2.1 四个脚本类型（贯穿其全部课程的骨架）— 等级 A

| 脚本类型 | 目的 | 原始表述（节选） |
|---|---|---|
| 晒过程 | 展示实力 / 手艺 / 质量 → 建立信任 | 把做产品或服务的过程拍出来 |
| 教知识 | 体现专业性 → 立专业人设 | 让观众觉得"这人有点东西" |
| 讲故事 | 通过案例或个人经历建立连接 → 拉近距离 | 讲自己的故事或身边人的故事 |
| 聊观点 | 获取同类支持 / 价值观认同 → 筛出真粉丝 | 观点 + 3 个理由即可构成脚本 |

来源：群响访谈正文（10100.com）、第三方课程笔记（bulang.net.cn）、ALLIN 课程大纲。
多源一致，可判定为其**核心方法论骨架**。

> 他本人表述：`脚本分四类，教知识脚本，晒过程脚本、讲故事脚本和说观点脚本。`
> 以及 `说观点脚本，太简单了，只要你支持你的观点，接下来说出 3 个理由，这个脚本完事了。`
> （来源：10100《拍短视频要流量，就 TMD 炸情绪！！！》，等级 A）

### 2.2 八大爆款元素 + 爆款词根 — 等级 A/C

八元素：`成本 / 人群 / 猎奇 / 反差 / 最差 / 头牌 / 怀旧 / 荷尔蒙`（多源一致）。
配套"36 个爆款词根"，作为选题素材库。

其自述的推导逻辑（等级 A，群响访谈）：
> `有人说你八大爆款元素在我的行业一定不好使，因为你薛辉没做过我的行业……但我知道观众想看啥。`
> 即：**方法不依赖行业知识，依赖对观众注意力的判断。**

### 2.3 情绪曲线 — 等级 A（最高价值的一条）

其本人给出的实操表述（群响访谈，节选）：

- 判断好文案的标准是**情绪曲线**：同一句话改到情绪更高就留下，改不动就走。
- 他给的评分示例：平铺直叙的展望 ≈ 负分；中立提问 ≈ 0 分；带数字的对比 ≈ 60 分；
  **武断、引发反驳欲的陈述 ≈ 80 分**（"你凭什么这么说，我要喷你，但我要听你说完"）。
- 提炼结论：**负面反差是最稳定的爆款元素。**

### 2.4 "加一个人物关系，自带情绪曲线" — 等级 A（对我们最直接可用）

其原话意思（群响访谈，节选）：
> `今天如果你去卖车，没意思，带着你未来丈母娘买车有情绪了。`
> `你讲修车知识没人听。你教你徒弟修车，骂你徒弟修车观众就听。`
> `人物关系会天然让观众有情绪……因为人物关系的背后是人物的任务线。`

即：**观众不为知识点停留，为关系中的强弱博弈停留。**

### 2.5 自然流拍摄与采访 — 等级 C（课程大纲转述，OCR 有损坏）

来自第三方转载的 ALLIN 课程大纲/思维导图（520mx、课程笔记站），文字有明显 OCR 损坏，
以下为**语义可确定**的部分：

- **自然流拍摄避忌（原文"九大禁忌"，条目数未完全确认）**：
  - 批评 IP 的情绪状态不对
  - 要求 IP 完全按稿 / 背稿
  - 打断 IP 说话
  - 跟 IP 说"刚才这段没拍上"
  - 让拍摄盖过表达 → 影响 IP 输出思路
  - 偏离 IP 风格
  - 中途频繁动灯 / 动收音
  - 疯狂切镜头 → 剪辑跳切，观众不知道看谁
  - 拍摄分不清主次 → 观众可能关注配角而不是主角
- **自然流采访技巧**：用"与 IP 目标拉一个对立面"的方式提问。对立方向包括
  `地域对立 / 关系对立 / 阶级对立 / 头牌对立 / 内外行对立 / 性别对立`。
  另有"负向假设"提问法（让对方给出进一步解释），以及"切点必须基于事实"的约束。
- **一句话目标**：`一顿饭拍出 30 条视频的采访技巧`（课程宣传语，非承诺）。

### 2.6 IP 强度分级与"假粉丝" — 等级 C

| 等级 | 特征 |
|---|---|
| 无人 IP | 剧情类内容，流量高但转化差 |
| 弱人物 IP | 出镜但不表达，缺乏人物辨识度 |
| 半强 IP | 正式表达但距离感强（**教学式内容**） |
| 强人物 IP | 自然对话式表达，展现真实价值观 |

配套概念：**假粉丝**（如影视解说号）——粉丝关注的是内容而不是人，商业转化极低。
变现链条：`人物 IP → 信任建立 → 成交转化`。

> 这一条对 Damon 直接相关：**"正式教学式表达"被其明确定义为半强 IP。**

## 5. 10+ 条候选编导原则 / Candidate Directing Principles

> 这些是**候选（candidate）**，未用于任何已发布视频。
> 每条都标了证据等级；等级 C/D 的条目**在升级为 testing 之前必须先取得更强证据**。

### DIR-101 — 选题是"加"出来的，不是想出来的

- **核心意思**：一个普通选题 + 一个爆款元素/词根 = 有冲突、有画面、有代入的选题。
  八元素：`成本 / 人群 / 猎奇 / 反差 / 最差 / 头牌 / 怀旧 / 荷尔蒙`。
- **来源证据**：群响访谈 + 第三方整理（等级 A/C，多源一致）。
- **适用场景**：Damon 已有一个强骨架（buyer-question-first），可直接在其上叠加元素，
  例如 `成本`（一箱多少钱）、`最差`（买家最容易买错的设备）、`内外行对立`（工厂 vs 贸易商）。
- **风险 / 不适用**：`荷尔蒙 / 整蛊 / 最差（负面极端）` 与 B2B 买家信任调性冲突；
  不能为了元素而制造不存在的负面结论。
- **可迁移性**：**高**。属于"给现有选题做加法"，不改变现有定位。

### DIR-102 — 加一条人物关系，而不是加一句文案

- **核心意思**：情绪不来自形容词，来自关系中的强弱博弈与任务线。
- **来源证据**：本人表述（等级 A）：`带上你未来丈母娘买车，就有情绪了`、
  `你教你徒弟修车，骂你徒弟，观众就听`。课程大纲另列六种对立方向（等级 C）。
- **适用场景**：Damon 与商户 / 工厂主 / 店员 / 同行的真实互动——本身就是现成的第二人物。
- **风险 / 不适用**：强行安排"师徒/婆媳"这类家庭关系会显得造作；
  B2B 场景适用的是**行业关系**（买家 vs 供应商、老手 vs 新手、工厂 vs 贸易商）。
- **可迁移性**：**高**。我们的分镜类型词里目前没有"对话"这一类，需要新增。

### DIR-103 — 四类脚本分工，我们现在只用了两类

- **核心意思**：`晒过程 / 教知识 / 讲故事 / 聊观点` 各有不同功能，
  应按目标（流量 / 人设 / 转化）配比使用。
- **来源证据**：本人表述 + 课程大纲（等级 A）。
- **适用场景**：V001–V006 全部落在"教知识 + 晒过程"。V008《工厂还是贸易公司？》
  天然属于**聊观点**；Damon 的转型经历属于**讲故事**。
- **风险 / 不适用**：观点型内容需要"偏激立场"，与"中立严谨的信息源"人设存在张力。
- **可迁移性**：**高**。但"聊观点"必须由 ChatGPT 定调，WorkBuddy 不自行产生观点。

### DIR-104 — 用情绪曲线自检，而不是用"内容是否完整"自检

- **核心意思**：让写稿的人先写一小段，然后**由外行读者画出自己的情绪曲线**；
  不懂的人判断最准，因为观众也是不懂的人。
- **来源证据**：本人表述（等级 A）。
- **适用场景**：Damon 脚本目前以"信息是否讲全"为验收标准；可增加一道"朗读情绪曲线"检查。
- **风险 / 不适用**：情绪曲线高 ≠ 对 B2B 买家有效；采购决策类内容需要"可信"多于"刺激"。
- **可迁移性**：**中高**。适合作为脚本审阅的一道补充工序，不替代现有规范。

### DIR-105 — 具体画面 > 抽象结论

- **核心意思**：抽象表述没有冲击力，要换成有画面感的人、数字、细节、动作。
- **来源证据**：等级 C（第三方整理，含其本人的对比例子）。
- **适用场景**：V005 已经做到（19.35/ctn 而不是"价格很有竞争力"）。
  V001 的宏观数字段可以换成"一个摊位一天做多少单"这类可感知细节。
- **风险 / 不适用**：不经核实的具体数字**绝对不能编**，这一条与 `AGENTS.md` §4 有直接冲突风险。
- **可迁移性**：**高**（但必须以真实采集为前提）。

### DIR-106 — 事件大于情绪：观众看的是"刚刚发生了什么"

- **核心意思**：视频要有"事件感"而不是"讲解感"；用事件性开头、随机性、第一视角
  制造"没法作假"的观感。
- **来源证据**：播客章节标题 `1:28:55 拍视频，事件大于情绪`（等级 A，但仅有标题，未逐字核实）；
  第三方 AI 总结中有"流量核心不是文案，而是事件感"（等级 D，**不可引用为原话**）。
- **适用场景**：Damon 在市场/工厂里本来就一直在"发生事情"（询价、验货、开箱、试机），
  但现有脚本把它们写成了"讲解流程"。
- **风险 / 不适用**：**制造事件 = 造假**，在 B2B 语境会直接毁掉信任。只能记录真实发生的事件。
- **可迁移性**：**中高**。方向正确，但证据等级偏弱，建议 ChatGPT 复核后再测试。

### DIR-107 — 自然流拍摄要保护出镜人的状态（九大拍摄禁忌）

- **核心意思**：不打断、不说"刚才这段没拍上"、不要求完全背稿、不频繁换灯、
  不疯狂切镜头、拍摄要分主次——因为出镜人的状态被破坏 = 素材报废。
- **来源证据**：课程大纲（等级 C，OCR 有损坏，条目数未确认）。
- **适用场景**：**这是对 Damon 实拍最有直接价值的一条。** Damon 是国内真人出镜、
  在真实市场/工厂拍摄，商户大多不是演员，一次拍摄被破坏就难以重来。
- **风险 / 不适用**：与"钩子拍 3 遍"的现有要求存在张力——需要在"保状态"和"保可用"之间定规则。
- **可迁移性**：**高**。建议升级为拍摄日现场纪律。

### DIR-108 — 采访靠"对立面 + 负向假设"引导，而不是提问清单

- **核心意思**：提问时给对方一个可对抗的对象（地域/关系/阶级/头牌/内外行/性别），
  或用负向假设逼出进一步解释；**切点必须基于事实**。
- **来源证据**：课程大纲（等级 C）。
- **适用场景**：Damon 未来采访工厂主、商户、懂行的人时，避免问出"我们质量很好"这类官方答案。
- **风险 / 不适用**：对抗式提问在中文商务语境里可能冒犯合作方，需要预演与关系前提。
- **可迁移性**：**中高**。适合用于 V008《工厂还是贸易公司》这类"判断型"内容。

### DIR-109 — 避免"半强 IP"：自然对话式表达 > 正式教学腔

- **核心意思**：`正式表达但距离感强（如教学式内容）` 被他明确定义为**半强 IP**；
  强 IP 是自然对话式表达 + 真实价值观。
- **来源证据**：第三方课程笔记（等级 C，但与其本人访谈口径一致）。
- **适用场景**：Damon 现有脚本大量采用 `B-ROLL + VO` 的正式英文旁白 +
  "Welcome to Linyi, China. I'm Damon — your guy on the ground." 的播报式身份句。
- **风险 / 不适用**：海外买家需要清晰信息，过度口语化可能降低专业感；
  且英文不是母语，自然对话难度更高。
- **可迁移性**：**高**。这是与 "Damon 必须持续真人出镜" 基线最互补的一条。

### DIR-110 — 固定识别符号 + 固定收尾

- **核心意思**：形成可识别的固定句/slogan，让观众记住"这是谁"。
- **来源证据**：其账号有固定收尾（`愿无知者有力，愿有力者前行`，等级 A）；
  Molly 也有固定 `check my bio`（见 `benchmark-molly-2026-09-20.md`）。
- **适用场景**：Damon 六条视频有 5 种不同的 CTA 文案 + 1 个 `None — intentional`。
- **风险 / 不适用**：固定收尾会削弱单条内容的新鲜感；需与品牌定位一致。
- **可迁移性**：**高**。但**收尾句的具体措辞属于品牌决策，WorkBuddy 不拟定**。

### DIR-111 — 内容配比 60% 泛选题 + 20% 人设 + 20% 转化

- **核心意思**：泛选题吸流量，人设选题让人喜欢你，转化选题让人信任你。
- **来源证据**：等级 C（第三方对谈整理），数字口径**未在本人原话中直接核实**。
- **适用场景**：可用于检视 V001–V012 的配比是否失衡。
- **风险 / 不适用**：该比例面向个人知识付费账号，**不必然适用于 B2B 出海采购账号**。
- **可迁移性**：**中**。建议只作为"自查视角"，不作为硬性排期规则。

### DIR-112 — 口播不能有"台词感"（不看逐字稿）

- **核心意思**：他明确有一条 `为什么不能看逐字稿`；另有第三方记录其原话
  `口播视频的核心就是不能让人有台词感`。
- **来源证据**：播客章节标题（等级 A，仅标题）+ 第三方拆解（等级 C）。
- **适用场景**：**这一条与我们现有规范直接冲突。** `scripts/README.md` 第 16 段标准要求
  `Full Script EN` 英文逐字稿 + timecode，演员按稿念就会产生台词感。
- **风险 / 不适用**：Damon 用英文口播、内容包含数字/价格/EXW 等**必须精确**的信息，
  完全脱稿风险更高。不能简单照搬。
- **可迁移性**：**高（但需要改造而非照搬）**。
  可行折中：逐字稿保留作为**信息依据**，另加一段"口语版"供拍摄时使用。

## 6. 下一阶段最值得测试的 3–5 个改动 / Recommended Tests for V007+

> 每条都是"人物动作 + 视觉 + 台词"三件一起设计，不是只改文案。

## 8. System Improvement Suggestions / 对更新闭环的建议

> 按 WB-002 第 7 节要求：**只提建议，不自行改规则。**

1. **给 research file 加"证据等级"列**（A/B/C/D，定义见本文件第 0 节）。
   本轮实践显示，同一个"薛辉方法"可能同时来自本人原话、课程笔记和 AI 总结，
   如果不标等级，ChatGPT 会误把二手提炼当原话。
2. **给 playbook 的 Principle Card 加 `Source confidence` 字段**，与现有
   `Source / 来源` 并列，取值为 `A / B / C / D`。
3. **给 Principle Card 加 `Test target` 字段**（打算在哪条视频、哪天测试）。
   否则 candidate 容易长期停在 inbox，不进入真实视频验证，闭环断在半途。
4. **在 playbook 的 14 个编导维度与 `scripts/README.md` 的 16 段交付标准之间加一张映射表**，
   防止两套结构长期漂移（例如 `editing` ↔ 第 16 段 Checklist、`cover-title` ↔ 第 12 段）。
5. **明确"外部方法论与现有规范冲突时的处理办法"**。本轮就撞到一次：
   DIR-112（不看逐字稿）与 `scripts/README.md` 第 4 段（要求 Full Script EN 逐字稿）
   直接对立。建议在 playbook 里固定一条：**冲突时先记录为 `conflict-open`，由 ChatGPT 裁定**，
   不要让 WorkBuddy 自行取舍。
6. **注意闭环的执行成本**。本轮从"外部研究"到"写 candidate"约需 20+ 次工具调用；
   如果每条 candidate 都要这么重，闭环难以长期跑。建议区分：
   轻量级 candidate（一两句话 + 单一来源）与重量级 research file（多来源交叉验证）。
