## B2B Safety Filter / B2B 过滤器

以下内容**不进入本轮 testing**：

- 为了流量使用未经证据支持的 `best / worst / cheapest / biggest`
- 荷尔蒙 / 整蛊 / 人为制造冲突
- 强迫商户给预设答案
- 把“对立采访”机械用于合作供应商
- 60/20/20 内容比例作为硬规则

我们的张力优先来自：

- 真实价格差异
- 采购风险
- 选择冲突
- 认知反差
- 真实人物任务
- 真实现场事件

## Review Rule / 复盘规则

每个测试至少观察 1–3 条真实发布视频，再由 Damon + ChatGPT 决定：

`testing → adopted / keep testing / retired`

不因为单条播放高就自动 adopted，也不因为一条数据低就立即 retired。
