### 核心拍摄原则

- 开场必须是**生产线旁真人 + 成品**，不要先拍厂房门头。
- 生产线是主角，仓库是结尾证明；不要让仓库占据超过本片约 20% 的主体时长。
- 机器运转镜头至少包含：广角全线、45°侧面、关键成型区近景、成品出来近景。
- 至少拍 2 个 Damon 真人动作镜头：拿成品观察、站在生产线旁指向工序/观察。
- 尽量保留机器真实声音作为 0.5–1.5 秒的转场，不要整条片只有音乐和 VO。

- exact raw material name / grade

### Shoot-day fact verification

Before final take, ask/observe and record:

1. 原料在现场的准确叫法是什么？是否允许公开视频说材料名称？
2. 实际顺序是：上料 → 加热 → 成型 → 切割/分离 → 堆叠？还是设备一体化完成？
3. 成品出来后有没有人工或设备检查？具体看什么？
4. 每包 / 每箱怎么计数？本片是否就是 V005 的同一 450ml SKU？若不是，不复用 450 pcs/ctn 数据。
5. 包装完成后是否直接进入仓库？

## 16. Shoot & Edit Checklist / 拍摄与剪辑检查单

### 到厂先确认

- [ ] 生产线是否当天正常开机。
- [ ] 哪一个位置允许 Damon 安全站立口播。
- [ ] 哪些机器区域不能靠近 / 不能拍。
- [ ] 原料准确名称能否公开。
- [ ] 实际工序顺序是否和脚本一致。
- [ ] 检查 / 堆叠 / 包装是否真实存在且允许拍。
- [ ] 是否允许拍工人正脸；没有明确同意则避开可识别正脸。
- [ ] 控制屏、订单单据、客户名、箱唛中的敏感信息是否需要避拍/后期打码。

### 必拍素材

- [ ] Damon + 生产线 Hook 至少拍 3 遍。
- [ ] 生产线广角 2 条，每条 6–10 秒。
- [ ] 生产线侧面运动镜头 2 条。
- [ ] 成型关键区域近景至少 3 条。
- [ ] 成品从线体出来的连续镜头至少 2 条。
- [ ] Damon 拿成品 / 看成品 2–3 条。
- [ ] 当天真实的检查 / 堆叠 / 包装动作。
- [ ] 包装箱 / 成品箱细节。
- [ ] 仓库纵深 3 条：正向、侧向、低机位。
- [ ] 机器自然声单独录 10–15 秒。
- [ ] 收尾口播至少 3 遍。

### 安全与剪辑

- [ ] 不为拍摄跨越护栏、伸手进入设备、干扰工人操作。
- [ ] 真人口播优先在机器噪音相对可控的位置；必要时后期补 VO。
- [ ] 前 1 秒就让观众看到产品 + 机器，不用厂门慢慢铺垫。
- [ ] 机器镜头平均 1–3 秒一切，成品从线体出来可保留 3–4 秒连续动作。
- [ ] 保留两处 0.5–1.5 秒真实机器声，增强现场感。
- [ ] 英文硬字幕全程保留；关键工序用大字，不要同时堆太多参数。
- [ ] 未核实技术参数一律不上字幕。
- [ ] 发布前检查：人物隐私、客户信息、订单、机器控制屏、内部价格全部无泄露。
