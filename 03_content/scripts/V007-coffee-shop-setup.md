## 2. Core Promise / 核心承诺

EN:

Instead of giving buyers another generic coffee-equipment list, Damon starts with one real question in the market: is one coffee machine enough to open a shop? He asks a real seller on camera, then follows the seller to see what should be considered next. The video ends with a simple sourcing principle: start with the menu and workflow, then build the equipment around them.

CN:

不再做“咖啡店设备清单”。Damon 在真实市场里拿一台咖啡设备作为起点，直接问真人商户：只买这一台够不够？商户现场回答，并带 Damon 去看第一批还要考虑的真实设备。最后由 Damon 总结买家采购逻辑：先确定菜单和流程，再围绕它配设备。

### 画面原则

- 不用市场外景做前 3 秒。
- 商户不是“采访嘉宾坐着答题”，而是现场一起完成任务的人。
- 商户回答之后必须有动作：**带 Damon 去看设备**。
- 设备镜头跟着商户刚刚说的内容走，不能先拍一堆再硬拼。
- 2–3 类设备足够；不要为了“完整”塞成 5–8 个产品清单。
- 尽量保留 1–2 处自然对话停顿、机器声、走路声，让画面有现场感。

### 拍摄当天必须确认

本条不提前写死具体设备类别。现场必须记录：

1. 商户真实建议的第一批设备是什么；
2. 每个设备准确中文名与通用英文名；
3. 商户把它归为“必须 / 常见 / 可选”中的哪一类；
4. 为什么与菜单 / 工作流程有关；
5. 现场是否真实有货、是否允许拍摄 / 操作；
6. 商户回答是否允许保留原声并发布；
7. 市场 / 门店门头准确名称。

### 禁止提前假设

- `espresso machine / grinder / water filter / ice maker / fridge` 等具体类别，只有现场真实确认后才能进最终成片文字。
- 不声称“所有咖啡店都需要同一套设备”。
- 不声称某一套配置是行业“标准答案”。
- 不报价格、MOQ、品牌、功率、产能，除非另行真实确认并符合仓库公开数据规则。

## 17. Shoot & Edit Checklist / 拍摄与剪辑检查单

### 拍摄前

- [ ] 再和商户确认：同意真人露脸 + 原声出现在公开视频。
- [ ] 说明不要求他背稿，只回答真实意见。
- [ ] 现场确认至少 1 台适合做 Hook 的咖啡设备。
- [ ] 现场确认市场 / 门店准确公开名称。
- [ ] 提前判断两个人站位：Damon + 设备 + 商户能否同时入镜。

### 对话拍摄

- [ ] 从 Hook 转商户尽量连续拍，不要明显“采访开机感”。
- [ ] 第一轮完整自然拍下来后，再补安全 take；不机械要求每句 3 遍。
- [ ] 商户回答时不打断。
- [ ] 必拍 `那你带我看一下`，让回答变成下一段行动。
- [ ] 商户走在前 / 侧面，Damon 跟着看，避免两个人并排僵硬走秀。
- [ ] 对话至少收一条双人中景 + 一条商户回答近一点的构图。

### 设备素材

- [ ] 商户每提一个关键设备，立刻补对应证明画面。
- [ ] 每个关键设备至少：全景 / 操作或手部 / 关键细节。
- [ ] 如果设备不能开机，不假装运行。
- [ ] 不为了凑数超过 3 类主设备。
- [ ] 单独录设备区自然声 10–15 秒。

### 剪辑

- [ ] 前 1 秒就是人物动作 + 设备，不用商城门头铺垫。
- [ ] 商户中文原声尽量保留；英文字幕做准确简洁翻译，不“美化成广告词”。
- [ ] 每 6–8 秒有新推进：问题 / 答案 / 任务 / 新设备 / 判断 / 结论。
- [ ] 商户答案决定设备顺序，不允许后期把别的设备硬套进他说的话。
- [ ] 保留至少 1 处走路声 / 机器声 / 自然停顿。
- [ ] 全程英文硬字幕；中文商户讲话用双语字幕处理。
- [ ] 未确认的价格、品牌、MOQ、功率、产能不上屏。
