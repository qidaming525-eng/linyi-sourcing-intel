## 2. Core Promise / 核心承诺

EN:

Instead of listing coffee equipment from a desk, Damon starts with one real buyer question inside the market: if a buyer only chooses one coffee machine, what else does the shop actually need? The answer comes from a real on-site interaction first, then Damon organizes it into a simple buyer-facing sourcing logic.

CN:

不再把咖啡设备拍成“机器清单”。Damon 在真实市场里先提出一个买家会问的问题：如果只买一台咖啡机，还缺什么？先让现场商户 / 从业者给真实回答，再由 Damon 把答案整理成买家能理解的采购逻辑。

### Spoken Version / Damon 现场口语版

Damon 不需要现场背完整 Full Script。真人段优先按下面短句拍：

1. `Just this machine — enough to open a coffee shop?`
2. 对商户中文提问：`如果我要从零开一家咖啡店，除了这台机器，第一批还要配什么？`
3. 商户真实回答，不打断，不要求重说成“标准答案”。

后期再用准确英文 VO 补全逻辑。

## 8. Facts / Products Used

### 已确认

- 中国酒店用品城存在可拍的 coffee equipment / 咖啡设备资源（V002 已使用该品类作为市场中的真实类别）。
- V007 是 buyer-mission 内容，不重复 V004 的 `sealing → ice → blending → portioning → workstation` 五段结构。

### 拍前 / 拍摄当天确认

本条**不提前写死**咖啡店 3–4 类设备，因为当前主库尚未记录现场准确品类。

拍摄当天必须记录：

1. 商户给出的第一批设备建议是什么；
2. 其中哪些设备现场真实存在且可拍；
3. 每个设备准确英文通用名；
4. 哪些属于“必须 / 常见 / 可选”，不要混说；
5. 是否能开机 / 操作；不能开机就只拍结构和动作；
6. 不报价格、MOQ、功率、品牌、产能，除非另行确认可公开并入库。

### 禁止提前假设

- espresso machine / grinder / water filter / ice maker / fridge 等具体类别，**只有现场确认后才能进入正式版正文**。
- 不声称“所有咖啡店都需要同一套设备”。
- 不声称某套配置是“标准答案”。

## 17. Shoot & Edit Checklist / 拍摄与剪辑检查单

### 拍摄前

- [ ] 现场先确认至少有 1 台适合做 Hook 的咖啡设备。
- [ ] 找一位真正懂该设备区的商户 / 店员，先说明只问真实意见，不要求演戏。
- [ ] 先问能否露脸；不能露脸再问能否录声音；都不行就用“Damon 询问后复述”备用方案。
- [ ] 确认准确市场门头名称，不在片中写错地点。

### 现场拍摄

- [ ] Hook 先拍 1 条完整自然版，不要第一句就连续打断重拍。
- [ ] 自然状态好时再补 1–2 条安全 take；不要机械要求“必须 3 遍”。
- [ ] 对话全程连续录，不要因为对方说得不标准就打断。
- [ ] 商户回答后追拍其刚提到的设备，形成“话 → 证据画面”。
- [ ] 每个真实设备至少拍：全景 / 手部动作 / 关键细节。
- [ ] Damon 至少有 3 类状态：问人 / 跟着看 / 自己总结。
- [ ] 单独录 10 秒设备区自然声。

### 剪辑

- [ ] 前 1 秒同时出现人物动作 + 设备，不用市场外景铺垫。
- [ ] 商户中文原声保留，英文字幕简洁翻译，不做过度美化。
- [ ] 每 6–8 秒必须出现新推进：问题 / 回答 / 新设备 / 新判断 / 结论。
- [ ] 禁止连续 10 秒以上纯设备扫货架而没有新信息。
- [ ] 如果商户回答与预想不同，**改脚本适应真实答案，不改答案适应脚本**。
- [ ] 不添加未经确认的价格、品牌、功率、MOQ、产能。
- [ ] 发布后在 `04_performance/videos.md` 特别记录：前 3 秒、平均观看时长、评论中是否有人继续问“我开什么店 / 我需要什么设备”。
