## 16. Shoot & Edit Checklist / 拍摄与剪辑检查单

### 到现场前

- [ ] 三款产品实物均确认可拍。
- [ ] 对应外箱尽量提前找出来。
- [ ] 再核一遍：450 / 1000 / 150 pcs per carton。
- [ ] 再核一遍：USD 19.35 / 9.40 / 11.25 per carton EXW。
- [ ] 仓库允许拍摄。

### 拍摄现场

- [ ] S1 Hook 真人至少拍 3 遍，保证英语口播有一遍顺畅。
- [ ] 每个产品拍：正面 / 侧面 / 手持 / 开合 / 外箱 / 箱唛。
- [ ] Damon 至少在 4–5 个镜头中出现，不能全片只有开头结尾两次真人。
- [ ] 拍仓库纵深，但不宣称“最大仓库”等未经验证比较级。
- [ ] 拍真实现场声 10–15 秒，供剪辑使用。
- [ ] 避免拍到不应公开的客户信息、联系方式、内部价格单、订单标签。

### 剪辑

- [ ] 前 1 秒直接看到 Damon + 大量整箱货，不放 Logo 动画。
- [ ] 价格出现时，整箱价字号最大；单个价字号小一级。
- [ ] `EXW` 每个价格段都可保留小标，结尾再明确一次 `FREIGHT NOT INCLUDED`。
- [ ] 英文字幕全程保留；价格、数量必须做独立视觉层级，不能只依赖字幕。
- [ ] 产品切换节奏约 2–3 秒一变化，避免连续 8 秒静止货架。
- [ ] 背景音乐不能盖住 Damon 真人声音；仓库现场声可短暂穿插。
- [ ] 如果拍到报价单/内部表格，只使用已经确认公开的字段，其余全部裁掉或模糊。
