## 6. Visual Plan

### 核心视觉逻辑

`V003 = showroom / sourcing model`

`V005 = warehouse / carton quantity / EXW carton price / MOQ`

仓库不是背景装饰，而是本条“真实整箱采购”的证据场景。

| 段 | 必拍画面 | On-screen |
|---|---|---|
| Hook | Damon 站在成排整箱货前，手拿真实产品；镜头先看到人 + 货 | `REAL EXW PRICES` / `MOQ: 1 CARTON` |
| Product 1 | 450ml 红白双色餐盒实物 → 外箱 → 一箱货 | `450ML FOOD BOWL` / `450 PCS/CTN` / **`$19.35/CTN EXW`** / 小字 `$0.043/pc` |
| Product 2 | 50ml 酱料杯实物 → 成叠产品 → 外箱 | `50ML SAUCE CUP` / `1000 PCS/CTN` / **`$9.40/CTN EXW`** / 小字 `$0.0094/pc` |
| Product 3 | 900ml MFPP 餐盒实物 → 打开/合上 → 外箱 | `900ML MFPP CONTAINER` / `150 PCS/CTN` / **`$11.25/CTN EXW`** / 小字 `$0.075/pc` |
| Comparison | 三款同时摆在桌面/货架，Damon 指向产品和外箱 | `DON'T COMPARE PRICE ALONE` |
| Ending | 仓库纵深 + Damon 走动/检查整箱货 | `EXW PRICE · FREIGHT NOT INCLUDED` |

### 拍摄注意

- 主信息用**整箱价**，单个价格只做屏幕小字辅助。
- 尽量让“实物 + 对应外箱”出现在同一段，增强整箱报价可信度。
- 如果拍摄当天某款产品没有对应库存外箱，不得用其他外箱假装对应；可只拍产品实物，并用确认过的报价字幕。
- 不把仓库规模说成“最大 / 最多 / 最大库存”等未经验证比较级。
- 仓库可以额外拍：通道纵深、整箱堆放、Damon 查看标签、拿样、核对外箱，为未来 warehouse / fulfillment 内容留素材。
