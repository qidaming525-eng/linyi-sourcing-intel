## 7. Facts / Products Used

Publicly verified before filming:
- 徐蒲坦位于临沂市郯城县胜利镇一带。
- 2023 齐鲁网/闪电新闻报道这里有约 2 公里长的自发性二手农机市场。
- 公开报道显示该地二手农机交易历史约三十年。
- 2025 年郯城县政府材料仍直接记录“徐蒲坦农机市场”及当地农机直播活动，说明该交易场景持续活跃。
- 当前公开经营主体资料可见二手拖拉机、二手收割机等品类。

Shoot-day facts required:
- 当天准确市场/区域名称和可见门头；
- 选中机器真实品牌、型号、年份；
- 是否存在真实、可信且可公开的小时数；
- 是否允许启动 / 试车 / 打开发动机舱；
- 商户是否允许露脸和原声；
- 如果出现价格：公开许可 + 报价条件。

Do not assume:
- 不提前说某台机器“车况好 / 无事故 / 原版 / 无大修”。
- 不凭外观判断发动机、变速箱、前后桥状态。
- 不保证小时表绝对真实。
- 不保证所有设备都可出口。
- 不保证某个具体海外国家可以进口二手机械。
- 不把单个商户的库存、价格或出口经历代表整个徐蒲坦市场。
- 不使用 largest / cheapest / best 作为 Damon 自己的无条件结论。

## 16. Shoot & Edit Checklist

### 拍摄前

- [ ] 到达后先确认真实市场/区域标识，记录准确中文名称。
- [ ] 找一位真正愿意公开交流的商户，先确认露脸 + 原声许可。
- [ ] 选一台外观有代表性、周围可安全拍摄的机器。
- [ ] 先问商户：年份 / 型号 / 是否能启动或试车；不要拍完才问。
- [ ] 如果准备问价格，先确认公开视频许可与价格条件。
- [ ] 大型机械拍摄必须保持安全距离，不站在启动车辆行驶路线内。

### 必拍素材

- [ ] 一条“机器两边 + Damon 中间走”的 Hook。
- [ ] 至少 2 个能看出市场纵深/密度的广角。
- [ ] 选中机器的整体 45°。
- [ ] 型号/铭牌特写（敏感编号视情况遮挡）。
- [ ] 轮胎 / 驾驶位 / 发动机舱等真实细节。
- [ ] 商户回答完整原声。
- [ ] 能启动就录完整发动声 5–10 秒；不能启动不要演。
- [ ] Damon 最后在市场纵深处做 CTA。

### 剪辑

- [ ] 前 1 秒就是大型机械 + Damon，不用航拍/门头慢慢铺垫。
- [ ] 2 公里只用 about / 约，不要做假地图量距动画。
- [ ] 商户中文回答用简洁准确英文字幕，不把普通回答包装成广告词。
- [ ] 发动机启动时尽量让音乐退掉，保留真实机械声。
- [ ] 每 5–8 秒发生一次推进：规模 → 地点 → 选机器 → 问人 → 测试 → 判断 → CTA。
- [ ] 不添加未经确认的马力、工时、年份、价格、出口国家、维修史。
- [ ] 如果外观明显翻新，不配 like new / excellent condition 等主观判断。
- [ ] 若拍到客户、车牌、联系方式、订单单据，必要时遮挡。
- [ ] 不做“买回去就能直接出口”的暗示。
